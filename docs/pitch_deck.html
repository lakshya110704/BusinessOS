The memory, proven

A returning vendor sends "woh pichla order ready hai?" — no product, no number, meaningless to a stateless bot. Because the system had loaded that vendor's two prior orders as context, it correctly read it as an order enquiry and surfaced it to the owner. Same text, different outcome — that's memory changing behavior.

This is relational memory — who the contact is, what they've ordered, running stats — and it's live today. Phase 2 deepens it into semantic memory: every conversation embedded and searchable, so the system can recall "what rate did we quote him for silk last month" from free text, not just structured fields.
